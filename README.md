# Blashteds-VMware-SVGA-II-128MB-Driver-Patch
After endless hours of deliberate tinkering with Ghidra on multiple different patch drafts, various PowerShell commands, failing checksums and the great help of AI for reverse engineering, I was able to successfully patch the problematic VMware SVGA II "vmx_svga.sys" driver with a two-byte patch to correctly reflect 128MB in Windows 2000 VMs.
